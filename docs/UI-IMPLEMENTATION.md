# Реализация утверждённого интерфейса — 2026-11-15

Реализация интерфейса для 0.1.0-alpha02. Исходный локальный пакет дизайна прочитан и не изменён; в публичный репозиторий не включён.

## Реализация

- Настоящий Compose: главный экран, приложения, сопряжённые устройства, помощь, настройка, сила и проверка вибрации. HTML/WebView и демонстрационные данные в приложение не добавлены.
- Главный экран соответствует иерархии макета; dynamic color Android 12+, системная тёмная тема, зелёная резервная палитра, прокрутка и safe drawing/IME insets. При крупном шрифте switch расположен ниже заголовка, декоративные значки строк убраны ради места для текста.
- `MainActivity` связывает UI с существующими состояниями и операциями. `AirInterface` принимает данные/действия и допускает тестирование без BLE. Состояние навигации и поиска — rememberSaveable.
- Все шесть результатов транспорта различимы. Ответ о физическом сигнале не меняет transport result. Отмена не изображает успех. Пустой выбор приложений не блокирует ручной тест; остальные условия send сохранены.
- Список приложений, package broadcasts, поиск по названию/package, сохранение индивидуального набора при all, выбор переименованных устройств и адреса для одинаковых имён сохранены. Сила 0/2/3 — с предупреждением о глобальной настройке.
- Настройка выводится по фактическим разрешениям и состоянию Bluetooth. Повторное обучение не меняет настройки и не включает пересылку. На главном доступны действия восстановления.
- Ключи DataStore не изменены. Изменён только default all на false согласно FUNCTIONALITY.md; сохранённые значения читаются как раньше. Подпись, applicationId, версия, разрешения, транспорт, очередь и listener не изменены.
- Новые VectorDrawable, adaptive и round launcher XML, отдельный monochrome. Manifest подключает roundIcon. PNG/SVG превью не попали в ресурсы APK.

## Выполненные проверки

- `gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleDebugAndroidTest`.
- 20 JVM tests: 16 прежних и 4 новых — условия ручного теста, приоритет статуса, отдельные сообщения результатов, defaults.
- Pixel 7 / Android 17: 8 instrumentation tests (5 UI, 2 прежних DeviceSmokeTest, 1 IconTest).
- Проверки UI: all сохраняет индивидуальный набор и блокирует строки; поиск по package; системный Back; отказ Bluetooth остаётся отказом; все результаты отображаются; пустой выбор разрешает тест; отмена не показывает подтверждение; настоящая Activity пересоздаётся без потери экрана, поиска и настроек.
- Скриншоты и визуальная проверка: светлая/тёмная резервная палитра, динамическая палитра, RU/EN, fontScale 1.0/2.0. Узкая область Compose 320 dp при 2.0 — без изменения глобальных настроек телефона.
- Иконка: Android VectorDrawable rendering при 48 dp, круг, rounded-square, squircle, цветная и tinted monochrome; загрузка AdaptiveIconDrawable и его monochrome на Android 17. Это не проверка всех OEM launcher.
- Instrumentation запущен напрямую через adb после `install -r`, чтобы не удалять пользовательскую установку и DataStore после тестов. Использован тот же AndroidJUnitRunner, что и connectedDebugAndroidTest. Глобальные разрешения/Bluetooth/оптимизация батареи не переключались.
- `git diff --check`; сравнение diff подтверждает отсутствие изменений BLE/notification реализации, signing/version/dependencies. Локальные чужие файлы сохранены.

- Скриншоты: `.private/ui-redesign/`: light, dark, large, english, *-apps, *-setup, error, icon-masks, icon-system. Скриншоты UI-тестов используют тестовые данные; device-home/device-apps показывают реальную установку. Эти локальные изображения не предназначены для публикации.

## Ограничения

- Не подтверждены физическая вибрация Fitbit Air, синхронизация Google Health, расход батареи и поведение BLE при аппаратном отключении во время отправки. Существующие пути cancel при disable/BT/address сохранены; UI проверен на моделируемой отмене. Новых аппаратных утверждений нет.
- TalkBack с озвучкой вручную не прогонялся. Проверены Compose semantics ролей/состояний и действия строк; это не заменяет полный accessibility audit.
- Монохромная иконка проверена Android-отрисовкой, но переключение themed icons в настоящем Pixel Launcher и другие OEM launcher не проверялись. Android 11 не запускался.
- 320 dp проверены ограничением области Compose, не отдельным устройством; landscape и исчерпывающий набор длинных названий вручную не проверены.
- Lint без ошибок; остаются предупреждения о версиях, старых/неиспользуемых ресурсах, screenWidthDp и конфигурации ресурсов. Обновление зависимостей не входит в редизайн.
